# Экспериментальная нижняя навигация

Ветка `feature/liquid-glass-nav-20261121`, база — `staging` после PR #9
(`acda1ab`). Изменена только оболочка навигации и необходимые отступы.
Заказы, корзина, авторизация, Telegram-уведомления и серверная конфигурация
не изменены. Старые `NavLink`, `CartBadge` и родительские активные маршруты сохранены.

## Запуск и сравнение

Из `frontend` в этой рабочей копии:

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

По умолчанию Vite слушает `http://127.0.0.1:5174`, API — существующий
`http://127.0.0.1:8001`. Если порт занят, используйте
`pnpm dev --port 5177 --strictPort` и соответствующий адрес.
Backend запускается отдельно привычным способом; менять его настройки не требуется.

Откройте адрес с нужным вариантом:

- `/catalog?nav=glass` — Glisse с автоматическим облегчённым режимом.
- `/catalog?nav=classic` — исходная белая панель.
- `/catalog?nav=glass-lite` — плавающая CSS-панель без загрузки и рендера Glisse.

Выбор сохраняется только в `localStorage` этого origin, ключ `bm:navigation:v1`.
Он сохраняется при переходах по разделам и перезагрузках; URL имеет приоритет.
При недоступном хранилище переключение через URL продолжает работать.
Первоначальный вариант — `glass`. Для повторной проверки полного эффекта после
облегчённого режима откройте `?nav=glass`.

## Реальный эффект и ограничения

Установлена **Glisse 0.6.0**, единственная новая зависимость, без обновления
остальных пакетов. API проверен по установленным `dist/index.d.ts` и `dist/index.js`:
`Glass` принимает стандартные `HTMLAttributes<HTMLDivElement>`; параметры линзы
задаются CSS-переменными `--lg-glass-bend`, `--lg-glass-dispersion`,
`--lg-blur`, `--lg-rim-shine`. [Документация](https://glisse.kelvinzhang.com/),
[исходники](https://github.com/0kzh/glisse).

В Chromium/Android Glisse преломляет живой backdrop самой панели без фильтрации
всего каталога. В WebKit/iPhone Glisse использует свой WebGL2-рендер содержимого
`main`, отмеченного `data-glisse-backdrop`. Это экспериментальный рендер:
точность сложного содержимого и внешних фотографий зависит от движка и CORS.
При отсутствии WebGL2 или backdrop-filter остаётся читаемая CSS-панель.

Glisse не монтируется при `prefers-reduced-motion`, сниженной прозрачности,
Save-Data, доступных аппаратных признаках слабого устройства (до 2 потоков или
до 2 ГБ памяти). `glass-lite` позволяет вручную облегчить эффект при медленной
прокрутке. При открытой клавиатуре и скрытом приложении Glisse размонтируется,
освобождая свои наблюдатели и работу рендера; ссылки остаются на месте.
Гарантировать FPS по аппаратным признакам нельзя.

Использованы существующие Telegram/system safe area и visual viewport:
панель поднимается над клавиатурой, нижний отступ контента резервирует её высоту,
отступ и безопасную область. При ширине 320 px все четыре ссылки помещаются,
их минимальная высота — 56 px. Диалоги остаются в нативном верхнем слое.

Проверки пройдены: `pnpm test` — 111 тестов в 18 файлах;
`pnpm build` — TypeScript и production-сборка. Glisse вынесен в отдельный
лениво загружаемый chunk (26,57 КБ gzip).
Браузеры, Playwright и скриншоты не использовались. Проверку на реальных
Telegram iOS/Android необходимо выполнить перед включением для покупателей.
Merge, deploy и изменения Render не выполняются этим экспериментом.
