# Полноэкранный режим Telegram

Изменения только во frontend. База, Django API, авторизация, корзина, заказы, фотографии и зависимости не меняются. Миграций и новых переменных Render нет.

## Поведение

- Существующий официальный SDK и `useTelegram` сохранены. После монтирования оболочки `ready()` и `expand()` вызываются один раз. При версии 8.0+ и доступном методе запрашивается `requestFullscreen()`, если приложение ещё не в fullscreen.
- Фактическое состояние читается из `isFullscreen`; `fullscreenChanged`, `fullscreenFailed`, события viewport и безопасных зон обновляют отступы. Исключение, отсутствие метода или отказ клиента оставляют обычный расширенный режим. Выход пользователя из fullscreen не вызывает принудительный повтор запроса.
- `disableVerticalSwipes()` вызывается при 7.7+, независимо от поддержки fullscreen. Закрытие через Telegram и существующая кнопка Back сохранены. Прокрутка документа, горизонтальные списки и масштабирование браузера не блокируются.
- `setHeaderColor('#ffffff')` при 6.9+ задаёт контраст системных элементов относительно светлой шапки. Верхняя зарезервированная зона получает белый фон и при прокрутке не пропускает под Telegram-кнопки контент страницы.

## Отступы и клавиатура

Используется прежняя цепочка `--app-tg-system-*` / `--app-tg-content-*` → `--app-safe-*`. Аппаратный отступ браузера `env(safe-area-inset-*)` и Telegram описывает одну область: берётся максимум, а не сумма. Внутренний отступ под элементы Telegram добавляется отдельно. Комбинированный верхний отступ применяется один раз к оболочке, без второго padding шапки и без значений под модель телефона.

`viewportStableHeight` остаётся основой высоты страницы. `visualViewport` определяет видимую область и фактически перекрытую клавиатурой часть: нижняя панель поднимается только на эту величину. Если клавиатура уже уменьшила layout viewport, повторного подъёма нет. Нижний аппаратный отступ панели не повторяется над клавиатурой. При необходимости поле прокручивается в видимую область над панелью; обычная ручная прокрутка это не запускает. Pinch zoom не считается клавиатурой. Слушатели и отложенный кадр удаляются при unmount.

Диалоги ограничены видимым прямоугольником с учётом всех четырёх безопасных краёв. Узкая шапка может увеличиться по содержимому, сохраняя логотип, название и адрес. Обычный сайт не запрашивает fullscreen и не загружает SDK без Telegram-контекста.

## Проверки

- Frontend: 100 тестов, включая поддержку/отказ fullscreen, однократный запуск, выход пользователя, события, устаревшие клиенты, очистку подписок, изменение viewport, overlay/resize клавиатуру и pinch zoom. Проверка TypeScript и production build.
- Локальный Edge с имитацией SDK и API: ширины 320/360/390/430, landscape 844×390, desktop 1100/1280, поворот открытого приложения, reload, обе модели клавиатуры, панель и поля, диалоги, отказ fullscreen и обычный браузер. Запросы к действующей базе и записи через backend не выполнялись.
- Эмуляция не подтверждает работу настоящего Telegram на устройствах. В частности, реальная высота нативных кнопок/клавиатуры и перехват свайпов требуют ручной проверки.

## Публикация и ручная проверка

1. Получить разрешение владельца на Merge PR в `staging`. Затем существующий Render автоматически соберёт обновление. Не менять флаги заказов, адрес, секреты и настройки базы/фотографий.
2. После успешной сборки закрыть Mini App и открыть заново через `@bmmsev_bot`. На совместимых iOS/Android проверить fullscreen, видимость системных кнопок и шапки, нижнее меню, прокрутку вверх/вниз и отсутствие сворачивания свайпом содержимого. Проверить штатное закрытие и Back.
3. Открыть каталог, «Идеи», корзину и профиль; проверить последние элементы страниц, модальное окно категорий, поля телефона и оформления при клавиатуре. Повернуть устройство в обе стороны и обновить страницу.
4. На Telegram Desktop/Web проверить доступный режим и корректный fallback. В обычном браузере проверить прежний запуск без Telegram SDK. Заказ для проверки этого frontend-релиза создавать не требуется.

Официальные основания: [методы Telegram WebApp](https://core.telegram.org/bots/webapps#initializing-mini-apps), [события](https://core.telegram.org/bots/webapps#events-available-for-mini-apps), [SafeAreaInset](https://core.telegram.org/bots/webapps#safeareainset), [ContentSafeAreaInset](https://core.telegram.org/bots/webapps#contentsafeareainset).
